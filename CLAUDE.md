# stack.oinam.com

The platforms we build on. Static HTML on GitHub Pages (`oinam/oinam-stack`), DNS on Cloudflare.
`/` is a hand-written index; `/cloudflare/` is a matrix of every Cloudflare product — what it does,
cost, alternatives — generated by `node tools/cloudflare.mjs` and committed; never edit it by hand. See `SETUP.md` for the sources, the build, and the Pages and DNS setup.

## Files

- `index.html` — the Stack index, by hand. Add a line when a new page lands.
- `cloudflare/index.html` — generated. One file, styles and script inline.
- `cloudflare.md` — generated with it: the same matrix as Markdown, for AI tools.
- `llms.txt` — by hand: lists each page's Markdown twin. Add a line when a new page lands.
- `tools/cloudflare.mjs` — fetches the docs and cloudflare.com, merges `data/cloudflare.json`, renders.
- `tools/cloudflare.html` — the page shell; the table goes into its `{{slots}}`.
- `data/cloudflare.json` — hand-written: product-page mapping, skips, Cost, Alternatives. Costs come
  from Cloudflare's own pricing pages on the day; never from memory.
- `.cache/` — fetched pages, gitignored. `--refresh` to refetch.
- `.github/workflows/refresh.yml` — weekly `--refresh` on GitHub Actions; commits only real changes,
  files curation work as one issue. Bump `checked` in `data/cloudflare.json` after re-checking costs.
- `CNAME` — `stack.oinam.com`, one line. Pages reads it; do not move or rename it.
- `.nojekyll` — serve the files as they are.

## Conventions

- 2-space indentation, never 4.
- Colours in OKLCH, as tokens on `:root`. Light by default, dark from `prefers-color-scheme` —
  no theme switch.
- Sans-serif system font stack (`system-ui`, …). Text sits at `max-width: 42rem`, `width: 96%`; the table is allowed `96rem`.
- Smart typography in the text: curly quotes and apostrophes (’ “ ”), proper dashes.
