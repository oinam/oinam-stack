# cloudflare.oinam.com

A matrix of every Cloudflare product — what it does, cost, alternatives. Static HTML on GitHub
Pages, DNS on Cloudflare. `index.html` is generated by `node tools/build.mjs` and committed; never
edit it by hand. See `README.md` for the sources, the build, and the Pages and DNS setup.

## Files

- `index.html` — generated. One file, styles and script inline.
- `tools/build.mjs` — fetches the docs and cloudflare.com, merges `data/products.json`, renders.
- `tools/template.html` — the page shell; the table goes into its `{{slots}}`.
- `data/products.json` — hand-written: product-page mapping, skips, Cost, Alternatives. Costs come
  from Cloudflare's own pricing pages on the day; never from memory.
- `.cache/` — fetched pages, gitignored. `--refresh` to refetch.
- `CNAME` — `cloudflare.oinam.com`, one line. Pages reads it; do not move or rename it.
- `.nojekyll` — serve the files as they are.

## Conventions

- 2-space indentation, never 4.
- Colours in OKLCH, as tokens on `:root`. Light by default, dark from `prefers-color-scheme` —
  no theme switch.
- Sans-serif system font stack (`system-ui`, …). Text sits at `max-width: 42rem`, `width: 96%`; the table is allowed `96rem`.
- Smart typography in the text: curly quotes and apostrophes (’ “ ”), proper dashes.
